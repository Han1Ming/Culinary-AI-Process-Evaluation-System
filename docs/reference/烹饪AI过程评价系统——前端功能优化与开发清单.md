# 烹饪AI过程评价系统——前端功能优化与开发清单

## 一、前端总体要求

- [ ] 保留现有 Vue 3、TypeScript、Element Plus 技术体系。

- [ ] 梳理现有路由、页面、组件、API、状态管理和 Mock 代码。

- [ ] 统一页面布局、导航、按钮和状态标签。

- [ ] 统一 API 请求封装、鉴权、错误处理和文件上传机制。

- [ ] 所有业务页面支持加载中、空数据、请求失败和无权限状态。

- [ ] 明确区分模拟数据、AI识别结果、教师复核结果。

- [ ] 前端不承担模型推理和复杂业务计算。

- [ ] 重要操作增加二次确认。

- [ ] 支持 1366×768 和 1920×1080 常见分辨率。

- [ ] 生产环境默认关闭 Mock。

## 二、工作台与首页

### 2.1 教师工作台

- [ ] 展示当前课程、班级、实训任务和实训时间。

- [ ] 展示实训总人数、已签到人数、未签到人数。

- [ ] 展示正在实训人数和已完成实训人数。

- [ ] 展示在线摄像头数量、离线摄像头数量。

- [ ] 展示各评价模块完成情况。

- [ ] 展示待教师复核数量和异常事件数量。

- [ ] 支持按课程、班级、实训任务筛选。

- [ ] 点击统计卡片可跳转到对应详情页面。

- [ ] 首页统计数据全部来自后端接口。

### 2.2 学生工作台

- [ ] 仅展示当前学生本人信息。

- [ ] 展示当前实训任务和任务状态。

- [ ] 展示本人签到状态。

- [ ] 展示本人各环节评价进度。

- [ ] 展示已归档的实训报告和历史成绩。

- [ ] 不允许学生查看其他学生的实训记录和成绩。

## 三、人脸识别签到模块

- [ ] 支持摄像头预览和设备选择。

- [ ] 展示当前课程、班级、实训任务和工位信息。

- [ ] 展示识别中、签到成功、识别失败、未注册等状态。

- [ ] 展示识别时间、识别置信度和识别截图。

- [ ] 对重复签到给出明确提示。

- [ ] 支持多人同时入镜时的结果列表展示。

- [ ] 支持教师人工补签，并记录补签人、时间和原因。

- [ ] 支持按课程、班级、日期、学生筛选签到记录。

- [ ] 支持查看签到记录详情和识别截图。

- [ ] 支持学生人脸信息注册、更新、注销的管理入口。

- [ ] 展示个人信息告知、授权状态和数据管理提示。

- [ ] 对摄像头不可用、网络中断、接口超时等情况提供恢复提示。

## 四、着装规范识别模块

- [ ] 展示当前学生、工位和实训任务。

- [ ] 展示实时画面或最近一次识别截图。

- [ ] 将各项着装要求拆分为独立检查项。

- [ ] 每项显示合格、不合格、待复核或未检测状态。

- [ ] 不合格项目展示原因和对应截图。

- [ ] 展示模型置信度和识别时间。

- [ ] 支持教师确认、驳回和修改结果。

- [ ] 教师修改时填写复核原因。

- [ ] 支持按学生、班级、课程和时间查询历史记录。

- [ ] 支持违规记录统计和导出。

## 五、食材预处理评价模块

- [ ] 展示当前学生、实训任务、食材名称和操作工位。

- [ ] 展示预处理视频或关键过程截图。

- [ ] 展示切配动作次数和单位时间动作频率。

- [ ] 使用曲线展示切配频率随时间的变化。

- [ ] 展示切丝/切片粗细、长度等均匀性分析结果。

- [ ] 展示操作连续性等可观测指标。

- [ ] 每项指标显示数值、等级和评分依据。

- [ ] 支持查看关键帧和对应时间点。

- [ ] 支持教师人工复核、修改分数和填写评语。

- [ ] 支持历史记录查询和结果导出。

- [ ] 对尚未实现或无法可靠视觉判断的指标，不显示虚构分数。

## 六、烹饪过程评价模块

### 6.1 四路视频监控

- [ ] 展示四路视频画面及工位编号。

- [ ] 展示摄像头名称、连接状态和视频流状态。

- [ ] 区分在线、离线、连接中、播放失败状态。

- [ ] 支持单路放大、全屏和返回四宫格。

- [ ] 支持切换摄像头与工位绑定信息。

- [ ] 显示后端提供的帧率、延迟或最近更新时间。

- [ ] 视频断流时显示明确错误状态和重连提示。

- [ ] 视频播放与AI事件推送分离：视频走媒体流，事件走WebSocket/SSE。

- [ ] 不以浏览器定时截图上传作为正式四路视频分析架构。

### 6.2 六个烹饪步骤时间轴

步骤包括：

1. 备菜
2. 焯水
3. 烧干锅
4. 加油润锅
5. 翻炒
6. 装盘

- [ ] 六个步骤按既定顺序展示。

- [ ] 每个步骤展示未开始、进行中、已完成、待复核、异常状态。

- [ ] 展示步骤开始时间、结束时间和持续时长。

- [ ] 展示识别置信度和最近更新时间。

- [ ] 支持点击步骤查看事件详情。

- [ ] 事件详情展示关键截图、时间戳、摄像头编号和识别说明。

- [ ] 支持查看步骤遗漏、顺序异常和超时事件。

- [ ] 支持教师确认、驳回或修正步骤结果。

- [ ] 教师修正需记录人员、时间、原结果、新结果和原因。

- [ ] 支持实训过程历史查询和事件回放入口。

### 6.3 异常与语音提示

- [ ] 展示异常事件列表和严重程度。

- [ ] 支持按工位、学生、事件类型和时间筛选。

- [ ] 支持异常事件确认和处理状态更新。

- [ ] 支持语音播报开关、音量和播报策略设置。

- [ ] 避免多工位语音提示串线。

- [ ] 网络或AI服务异常时提示暂不可用，不伪造识别结果。

## 七、菜品成品分析模块

- [ ] 支持移动端拍照上传和本地图片上传。

- [ ] 支持图片预览、删除、重新上传和格式/大小校验。

- [ ] 将图片与学生、实训任务、菜品记录关联。

- [ ] 展示食材外观、色彩搭配、摆盘美观、工艺呈现、创意特色等评价维度。

- [ ] 每个维度展示分数、评价理由和改进建议。

- [ ] 展示总分、等级和生成时间。

- [ ] 支持查看原图和分析结果。

- [ ] 支持教师修改分数和评语，并保留AI原始结果。

- [ ] 明确照片分析不能直接判断真实口味、内部熟度和食品安全。

- [ ] 支持历史菜品评价查询和报告导出。

## 八、综合评价与报告

- [ ] 汇总签到、着装、食材预处理、烹饪过程和菜品成品评价。

- [ ] 展示各环节分数、权重和总分计算规则。

- [ ] 区分AI初评、教师复核和最终成绩。

- [ ] 支持教师复核后确认归档。

- [ ] 每个分数可追溯到来源记录、图片或视频事件。

- [ ] 归档时保存评价规则版本和各项原始分数。

- [ ] 支持按课程、班级、学生、任务和时间筛选。

- [ ] 支持生成学生个人实训报告。

- [ ] 支持PDF打印/导出和Excel成绩导出。

- [ ] 支持查看历史报告和成绩修改记录。

- [ ] 已归档报告不得因后续权重调整而自动改变。

## 九、学生实训档案

- [ ] 展示学生基本信息和所属班级。

- [ ] 展示历次实训任务、菜品和完成时间。

- [ ] 展示各次实训分项得分和综合成绩。

- [ ] 使用图表展示成绩趋势。

- [ ] 展示常见问题和教师评语。

- [ ] 支持按学期、课程和实训类型筛选。

- [ ] 学生只能查看本人档案；教师按授权范围查看学生档案。

## 十、课程、任务、工位与设备管理

- [ ] 课程信息新增、编辑、查询和停用。

- [ ] 班级和学生名单管理。

- [ ] 实训菜品和菜谱信息管理。

- [ ] 实训任务创建、发布、开始、暂停和结束。

- [ ] 实训任务关联课程、班级、学生、菜品和评价规则。

- [ ] 工位新增、编辑和状态管理。

- [ ] 摄像头设备登记、编号和启停管理。

- [ ] 摄像头与工位绑定和解绑。

- [ ] 摄像头连接测试和异常记录查看。

- [ ] 设备管理操作记录可追溯。

## 十一、智能AI老师（扩展模块）

- [ ] 保留流式问答交互。

- [ ] 支持常见烹饪知识快捷提问。

- [ ] 支持图片和PDF等约定格式附件上传。

- [ ] 展示历史对话和会话管理。

- [ ] 按课程、菜系、操作规范组织知识库入口。

- [ ] 展示回答引用的知识来源。

- [ ] 支持复制回答和用户反馈。

- [ ] 明确AI老师不能直接修改正式成绩或教师复核结论。

## 十二、权限、隐私与安全交互

- [ ] 页面路由按角色控制。

- [ ] 学生、教师、管理员展示不同菜单和操作。

- [ ] 前端隐藏无权限按钮，但不将前端权限作为安全边界。

- [ ] 对删除、归档、成绩确认等操作增加二次确认。

- [ ] 敏感信息页面避免不必要展示和复制。

- [ ] 人脸信息相关页面展示用途、授权和管理提示。

- [ ] 文件上传校验类型、大小和数量。

- [ ] Token失效时清理登录状态并跳转登录页。

- [ ] 不在浏览器日志中输出密码、Token或敏感个人信息。

## 十三、工程质量与联调

- [ ] 统一API前缀和版本，例如 /api/v1/...。

- [ ] 统一TypeScript请求/响应类型。

- [ ] 统一分页、排序、筛选和错误响应格式。

- [ ] 统一日期时间格式及本地时区展示规则。

- [ ] WebSocket支持断线重连、心跳和重复连接清理。

- [ ] SSE支持中断、重试和结束状态处理。

- [ ] 文件上传显示进度和失败原因。

- [ ] 页面刷新后按业务需要恢复查询条件或任务上下文。

- [ ] 长列表使用分页或虚拟滚动。

- [ ] 关键页面完成组件测试和端到端流程测试。

- [ ] 生产构建不包含开发Mock数据和调试入口。

- [ ] 提供 .env.example 和部署配置说明。
